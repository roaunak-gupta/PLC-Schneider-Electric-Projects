# PLC – Schneider Electric Projects
This repository contains a collection of industrial automation Lesson, Exercises, Projects developed using Schneider Electric PLCs, focusing on PLC programming, machine automation, Ladder logic, HMI integration, sensors, motor control etc. Projects are developed and simulated using EcoStruxure Machine Expert Basic with practical automation concepts and real-world industrial applications.

## Technologies & Tools
- Schneider Electric PLC
- EcoStruxure Machine Expert
- EcoStruxure Machine Expert – Basic
- Ladder Logic (LD)
- HMI
- Sensors & Actuators
- Timers & Counters
- Motor Control
- Industrial Automation

## Projects Covered
- Motor Start/Stop Control
- Conveyor Belt Automation
- Traffic Light Control
- Automatic Tank Level Control
- Sensor-Based Automation
- Timer & Counter Applications
- Sequential Control Systems
- HMI-Based Control
- Industrial Machine Automation

## Objective
The purpose of these projects is to develop practical knowledge of PLC programming, automation logic, industrial control systems, troubleshooting, and Schneider Electric automation platforms.

This repository is continuously updated as I learn and develop new PLC automation projects.
